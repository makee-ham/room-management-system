# 8월 객실 마스터·장기투숙 기능 결정안

이 문서는 사용자가 제공한 `객실현황(26.08)`의 `8월`·`장기-결제` 시트를 바탕으로 정리한 객실 기준정보와 다음 기능 결정안이다. 개인정보·PIN·자유문구 속 고객명은 앱 fixture에 가져오지 않는다.

## 이번 반영 확정

- 최신 객실 정본은 `8월` 시트의 121개 객실이다.
- 타입 구성은 스탠다드 22개, 프리미어 51개, 파셜 오션뷰 13개, 패밀리 투룸 35개다.
- 엘리베이터 표기는 A 33개, B 21개, C 56개이며 공란 11개는 `엘리베이터 미기재`로 보존한다.
- 공란 객실은 139, 358, 359, 449, 458, 461, 553, 559, 628, 629, 762호다. 위치를 추정하지 않는다.
- 객실 목록·상세·청소 대상·메이드별 순서 보드에 객실 호수, 타입, 엘리베이터 위치를 함께 표시한다.
- 기존 시나리오용 9개 객실만 예약·청소 상태 근거를 유지하고, 앱에 상태가 연결되지 않은 객실은 `운영 상태 미입력`으로 구분한다. 다만 시트의 공란·색·배치가 서로 다른 해석을 낳아 운영·장기투숙 여부를 먼저 확인해야 하는 객실은 `확인 보류`로 올리고 추정하지 않는다.
- 타입별 청소요금 정본은 시트 값인 `스탠다드 16,000원 / 프리미어 20,000원 / 파셜 오션뷰 20,000원 / 패밀리 투룸 30,000원`으로 확정한다. 더 이상 임시값이나 미확정 값으로 부르지 않는다.
- 762호는 스탠다드 타입과 16,000원 기본 청소요금만 정본으로 확정되어 있다. 엘리베이터 위치, 운영 상태, 장기투숙 여부는 근거가 없으므로 모두 `확인 보류`로 유지한다.
- 시트의 별도 숫자 `타입` 1/1.5/1.5/2는 의미 범례가 없어 청소 난이도·인원 계수로 추정하지 않는다.

## 시트에서 확인된 장기투숙 운영

- 현재 장기투숙으로 명시된 객실은 11개다. 종료된 장기투숙은 활성 목록과 분리되어야 한다.
- 시작 예정, 현재 투숙, 퇴실·종료가 자유문구와 행 색으로 섞여 있어 상태 변경 이력이 덮어써질 위험이 있다.
- 월별 결제 칸에는 날짜, 분할 납부, 퇴실 메모가 한 셀에 섞여 있다.
- 장기 객실 날짜 칸에도 청소 담당으로 보이는 이름이 반복되어, 장기투숙 청소가 단발 업무가 아니라 반복 일정일 가능성이 높다. 색·공란에는 범례가 없어 상태로 자동 해석하지 않는다.
- 월 시트가 오른쪽으로 계속 늘어나는 방식이므로 앱에서는 월 전환과 과거 월 스냅샷을 분리한다.

## 권장 기능 확정안

### 1차: 장기투숙 마스터 + 반복 청소

- 장기투숙 상태: `입실 예정 / 투숙 중 / 퇴실 예정 / 종료`.
- 객실, 시작일, 종료 예정일, 회사·계약 구분, 내부 메모를 구조화한다. 고객 식별정보는 관리자만 조회한다.
- 청소 주기와 요일, 마지막 청소일, 다음 청소일, 일시 중지·건너뛰기 사유를 기록한다.
- 생성된 청소는 기존 전날 배정 화면에 `장기투숙 정기 청소` 근거로 자동 포함하고, 담당·순서·검수·폭탄방 정책은 일반 청소 흐름을 재사용한다.
- 객실 변경 시 이전 객실 기록을 삭제하지 않고 이동 이력을 남긴다.

### 2차: 월별 결제 원장

- 월 청구액은 숫자로 저장하고 `예정 / 일부 납부 / 완납 / 연체 / 종료` 상태를 계산한다.
- 한 달에 여러 번 납부할 수 있는 거래 원장으로 분할 납부를 지원한다.
- 퇴실·종료일 이후에는 다음 달 청구 생성을 중단하고, 수정 전후 값과 수정자를 감사 이력에 남긴다.
- 청소 주급과 장기투숙 결제는 서로 다른 원장으로 유지한다.

### 후속: 객실 운영 보조

- `운영 시작 예정 / 운영 중 / 운영 중지`를 자유문구 대신 구조화해 신규 객실 시작일을 관리한다.
- 카드키 보유 현황은 객실 PIN과 분리된 실물 자산 대여·회수 기록으로 설계한다.
- 세스코 같은 정기 작업은 업체별 전용 화면보다 범용 `정기 점검 작업`으로 만들어 객실 묶음, 회차, 완료 증빙을 관리한다.
- 색상은 보조 표현으로만 쓰고 모든 상태에 상태명·아이콘·이유·범례를 제공한다.

## 해결된 결정

- 청소 단가는 시트 값을 운영 정본으로 사용한다: 스탠다드 16,000원, 프리미어 20,000원, 파셜 오션뷰 20,000원, 패밀리 투룸 30,000원.
- 객실 상태 근거가 불명확하면 `확인 보류`로 표시하고, 특히 762호의 위치·운영·장기투숙 여부를 추정하지 않는다.

## 아직 사용자 확인 필요

1. 장기투숙은 `마스터 + 반복 청소`를 먼저 확정하고 결제 원장은 2차로 분리할지.
2. 엘리베이터 미기재 11개 객실의 위치와 762호의 운영·장기투숙 여부.
