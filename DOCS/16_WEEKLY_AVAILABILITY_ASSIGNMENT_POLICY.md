# 주간 근무 가능일·근무 기록·관리자 전날 배정 정책

- 확정일: 2026-08-16
- 근거: 운영 관리자의 명시적 결정, GitHub issue #2, #4, #6, #8, #10, #14, #16, #18
- 상태: 청소 담당 결정 방식의 현재 정본

## 1. 적용 우선순위

이 문서는 청소 근무 가능일과 담당 배정에 한해 `DOCS/FINAL_UX_AUDIT.md`와 `DOCS/14_CLICKABLE_WIREFRAME_HANDOFF.md`의 `매일 근무 등록`, `공개 일감`, `메이드 선점`, `재공개` 규칙을 대체한다. 다른 객실·예약·PIN·검수·주급·감사 정책은 기존 정본을 유지한다.

## 2. 주간 운영 흐름

1. 메이드는 일요일 오후부터 22:00까지 다음 주 월요일–일요일의 근무 가능일을 모두 선택해 제출한다.
2. 마감 전에는 제출 내용을 직접 수정할 수 있다. 마감 뒤에는 기존 제출을 유지하고 관리자에게 변경 요청을 보낸다.
3. 관리자는 일요일 밤 또는 월요일 근무 시작 전에 모든 메이드의 제출·미제출·변경 요청과 요일별 가능 인원을 한 화면에서 확인한다.
4. 시스템은 배정 대상일에 체크아웃하는 객실과 해당 날짜에 연박 청소를 신청한 객실을 `청소대상 객실`에 자동 포함한다.
5. 관리자는 자동 대상 외 재청소·현장 요청을 같은 화면에서 직접 등록해 추가할 수 있다. 동일 대상일·객실·청소 유형의 중복 등록은 차단한다.
6. 관리자는 `전체`와 확정된 네 객실 타입 필터로 청소대상을 좁혀 보며, 각 타입의 대상 수와 객실당 고정 청소 요금을 함께 비교한다. 필터는 표시만 바꾸고 전체 대상의 담당 상태·저장 조건·순서를 바꾸지 않는다.
7. 각 근무일 전날 밤, 관리자가 다음 날 청소 대상 객실마다 담당 메이드를 직접 선택하고 별도의 `메이드별 타입 배정·청소 순서` 보드에서 같은 메이드가 청소할 객실의 순서를 `1번째`부터 끊김 없이 지정한다.
8. 보드는 메이드마다 네 객실 타입별 배정 개수와 총 객실 수·총 청소비를 함께 보여준다. 담당을 선택·해제·변경하면 관련 메이드의 타입별 개수와 총 청소비를 즉시 다시 계산하고, 미배정 객실은 누구의 개수와 금액에도 포함하지 않는다. 타입 필터는 이 전체 배정 요약에 영향을 주지 않는다.
9. 순서는 객실별 담당 행이 아니라 메이드별 보드에서 같은 메이드에게 배정된 객실끼리만 위·아래로 조정한다. 담당을 바꾸면 해당 객실은 새 메이드 순서의 마지막으로 이동하고 이전·새 메이드 양쪽 순서를 연속 번호로 다시 계산한다.
10. 담당 선택 목록에는 해당 날짜를 `근무 가능`으로 제출한 메이드만 표시한다. `근무 불가` 또는 `미제출` 메이드는 예외 배정할 수 없으며, 먼저 가능일 변경 요청을 승인해 일정 기록을 바로잡아야 한다.
11. 저장 시 담당과 청소 순서가 해당 메이드의 `내 업무`와 `알림`에 통보된다. 배정·순서 변경은 기존 담당 구간과 이전 순서를 삭제하지 않고 변경 이력을 추가한다.
12. 가능일 제출 버전, 관리자 배정·순서 통보일, 실제 청소 수행 완료일을 서로 다른 기록으로 주차별 보존하고 관리자가 사람·주차를 선택해 과거 기록을 조회한다.

### 예약 시각 기반 특수 입퇴실 판정

- 객실의 예정 체크인은 `16:00`, 예정 체크아웃은 `11:00`을 기본 기준으로 한다.
- 예정 체크인이 16:00보다 이르면 `얼리 체크인`, 예정 체크아웃이 11:00보다 늦으면 `레이트 체크아웃`으로 자동 판정한다. 정확히 16:00·11:00이면 각각 기본 상태이며 특수 상태를 표시하지 않는다.
- 상태와 차이는 별도 수동 선택값이 아니라 실제 예정 시각에서 계산한다. 예를 들어 체크인 15:00은 `얼리 체크인 · 1시간`, 체크아웃 13:00은 `레이트 체크아웃 · 2시간`이다.
- 예약 입력은 기존 정책과 같이 1시간 단위를 유지하며, 예약 시각이 바뀌면 객실 카드·상세·특수 상태 필터·청소 배정 일정에 같은 결과를 즉시 반영한다.
- 과거 수동 얼리·레이트 표식이 남아 있더라도 판정 근거로 쓰지 않는다. 예정 시각이 없으면 상태를 추정하지 않고 `일정 없음`으로 표시한다.

## 3. 권한

### 메이드

- 본인의 다음 주 근무 가능일만 제출·수정·변경 요청할 수 있다.
- 관리자에게 통보받은 본인 업무만 볼 수 있다.
- 객실을 선택하거나 본인·다른 메이드의 담당을 확정·변경할 수 없다.
- 담당 취소가 필요하면 사유를 포함해 관리자에게 요청하며, 결정 전까지 기존 담당을 유지한다.

### 관리자

- 전체 메이드의 주간 가능일 제출 현황을 볼 수 있다.
- 전날 배정 화면의 주간 요약은 `메이드 주간 근무표`로 부른다. 각 날짜 셀은 `✓ / × / —` 도형만 표시하고, 표 아래 범례와 메이드명·요일·가능 여부를 포함한 접근성 이름으로 의미를 보완한다.
- 대상일의 체크아웃·연박 신청에서 자동 구성된 청소대상과 관리자가 직접 등록한 대상을 한 목록에서 볼 수 있다.
- 전체와 네 객실 타입별로 청소대상을 좁혀 보고 각 타입의 대상 수·객실당 고정 청소 요금을 비교할 수 있다. 타입 필터에 숨은 객실도 전체 배정·저장 범위에 유지한다.
- 자동 대상 외 청소대상을 직접 등록할 수 있으며 자동·직접 등록 근거를 바꾸거나 숨기지 않는다.
- 다음 날 청소 대상 객실의 담당을 생성·변경·보류할 수 있다.
- 별도의 메이드별 타입 배정·청소 순서 보드에서 각 메이드의 네 타입별 배정 개수·총 객실 수·총 청소비를 비교하고, 같은 메이드에게 배정된 객실의 청소 순서를 지정·변경할 수 있다. 미배정 객실에는 타입 개수·금액·순서를 부여하지 않는다.
- 해당 근무일을 `가능`으로 제출한 메이드만 배정 후보로 본다.
- 근무 불가·미제출 메이드를 담당 선택 목록이나 직접 배정 목록에 노출하지 않는다.
- 과거 주차와 메이드를 선택해 가능일 제출·배정 통보·실근무 완료일을 구분해 볼 수 있다.
- 담당 취소 승인과 재청소 인계도 공개 목록으로 보내지 않고 직접 재배정한다.

## 4. 상태와 감사 이력

- 가능일 제출: `미제출 / 작성 중 / 제출 완료 / 변경 요청`
- 객실 배정·순서: `미배정 / 저장 전 / 통보 완료 / 변경 통보 완료`
- 청소대상 타입 필터: `전체 / 스탠다드 더블 로프트 / 프리미엄 더블 로프트 / 파셜 오션뷰 프리미엄 더블 로프트 / 파셜 오션뷰 패밀리 투룸 로프트`
- 청소대상 등록 근거: `자동 · 내일 체크아웃 / 자동 · 연박 청소 신청 / 직접 등록`
- 주간 근무 기록: `가능 제출(계획) / 담당 통보(예정) / 실근무 완료(수행 실적)`
- 저장 조건: 모든 다음 날 대상 객실에 해당 날짜 근무 가능 메이드가 배정되고, 메이드별 청소 순서가 1부터 끊김 없이 지정되어야 한다.
- 감사 이력: 대상일, 객실, 청소 유형, 자동·직접 등록 근거, 이전 담당·순서, 새 담당·순서, 관리자, 시각, 변경·취소 사유를 보존한다.
- 가능일 제출은 수정 시 이전 버전을 삭제하지 않고 새 버전을 추가한다. 주차 마감 스냅샷은 당시 표시 이름과 함께 보존한다.
- 실제 근무일은 정상 청소 수행 회차의 현장 완료일을 기준으로 하며, 가능일만 제출했거나 배정만 받은 날짜를 실제 근무로 세지 않는다.
- 현재 주 제출·재배정은 과거 주차 스냅샷과 완료 수행 기록을 덮어쓰지 않는다.
- 메이드 알림에는 본인 업무와 변경 내용만 포함하며 다른 메이드의 일정·배정은 노출하지 않는다.

## 5. 프로토타입 표현 범위

- `WIREFRAME/index.html`은 예약 체크아웃·연박 신청 fixture에서 자동 청소대상을 계산하고, 결정적 메모리 상태와 과거 주차 fixture로 타입별 보기·직접 등록·배정·메이드별 순서 보드·통보·근무 기록 조회를 시뮬레이션한다.
- 실제 서버 저장, 다중 관리자 동시성, 푸시·SMS 발송은 구현한 것으로 표현하지 않는다.
- 모든 객실·인명·단가·시간은 실제 운영 데이터가 아닌 데모 fixture다.

## 6. 수용 기준

- 메이드 화면에 공개 일감 목록이나 객실 선택 행동이 없다.
- 메이드는 일요일에 다음 주 7일 가능 여부를 제출하고 마감 전 수정 또는 마감 뒤 변경 요청을 할 수 있다.
- 관리자는 전체 제출 매트릭스와 다음 날 객실별 담당 선택을 한 화면에서 처리한다.
- 관리자 `메이드 주간 근무표`의 셀에는 `가능 / 불가 / 미제출` 한글을 반복하지 않고 `✓ / × / —`만 표시하며, 가로 넘침 없이 전체 7일을 보여준다. 스크린리더에는 메이드명·요일·상태를 함께 전달한다.
- 배정 대상일에 체크아웃하는 객실과 해당 날짜의 연박 청소 신청 객실은 별도 선택 없이 청소대상 목록에 자동 포함된다.
- 관리자는 자동 대상 외 객실을 같은 화면에서 직접 등록해 즉시 배정 목록에 추가할 수 있고, 같은 대상일·객실·청소 유형의 중복 등록은 차단된다.
- 각 청소대상 행은 `자동 · 내일 체크아웃`, `자동 · 연박 청소 신청`, `직접 등록` 중 하나의 등록 근거를 표시한다.
- 객실별 담당 선택에는 객실 호수·객실 타입·청소 요금이 항상 보이고, 얼리 체크인·레이트 체크아웃이 있으면 조정 체크인·체크아웃 시각을 함께 보여준다.
- 전체와 네 객실 타입 필터에는 대상 수와 객실당 고정 청소 요금이 보이고, 필터를 바꿔도 메이드별 전체 순서·미배정 수·저장 조건은 변하지 않는다.
- 체크인 15:00은 `얼리 체크인 · 1시간`, 체크인 16:00은 기본 체크인으로 자동 판정되며 수동 얼리 선택값은 없다.
- 체크아웃 13:00은 `레이트 체크아웃 · 2시간`, 체크아웃 11:00은 기본 체크아웃으로 자동 판정되며 수동 레이트 선택값은 없다.
- 예약 시각 변경 결과가 객실 카드·상세·필터와 청소 배정 일정에서 동일해야 한다.
- 담당 목록에는 해당 날짜 `가능` 제출자만 보이며 `불가`·`미제출` 메이드는 선택지에 없다.
- 청소 순서 이동 컨트롤은 객실별 담당 행이 아니라 메이드별 청소 순서 보드에만 있다. 관리자는 같은 메이드에게 배정된 객실의 순서를 위·아래로 변경할 수 있고 첫 객실의 위 이동과 마지막 객실의 아래 이동은 잠긴다.
- 담당 변경 시 해당 객실은 새 메이드 순서의 마지막으로 이동하며 양쪽 메이드 순서가 1부터 끊김 없이 다시 계산된다.
- 담당을 선택·해제·변경할 때마다 근무 가능 메이드별 네 객실 타입의 배정 개수가 즉시 갱신된다. 0건인 타입도 숨기지 않으며, 타입 필터를 바꿔도 전체 배정 기준 개수는 유지하고 미배정 객실은 제외한다.
- 미배정 객실이 있거나 선택된 담당이 해당 날짜 근무 가능자가 아니거나 메이드별 순서가 연속되지 않으면 저장·통보가 잠긴다.
- 저장 뒤 메이드의 내 업무·알림은 지정 순서대로 표시되고 관리자 이력에는 이전·새 담당과 순서가 함께 남는다.
- 관리자는 주차·메이드를 필터링해 가능 제출일·배정 통보일·실근무 완료일을 과거에도 구분해 조회할 수 있다.
- 메이드 역할로 관리자 배정 화면·상세 URL에 직접 진입할 수 없다.
