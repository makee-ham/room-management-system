## 결과 요약

배정 대상일의 체크아웃 fixture 4건과 연박 청소 신청 fixture 1건이 청소대상 객실에 자동 포함되고, 기존 직접 등록 1건과 출처별로 구분되는지 확인했다. 객실 호수·타입·요금·특수 시각과 `가능` 메이드만 표시하는 기존 배정 규칙을 유지하면서 `전체 + 네 객실 타입` 필터에 대상 수와 객실당 고정 청소 요금을 표시했다. 객실 행에서는 담당만 고르고, 별도 `메이드별 청소 순서` 보드에서 전체 배정을 메이드별 1–N번으로 조정하도록 분리했다. `청소대상 직접 등록`에서 1208호 퇴실 청소를 추가하자 목록이 6건에서 7건으로 늘고 프리미엄 타입 필터로 자동 전환됐으며 같은 객실·청소 유형의 재등록은 차단됐다.

메이드별 보드의 타입 개수·총 객실 수 실시간 갱신 로직은 기존 브라우저 검증 범위다. 확정 단가 기준 기대 합계는 김민지1의 스탠다드 2·패밀리 1이 62,000원, 이서연의 프리미어 1·파셜 오션뷰 1·패밀리 1이 70,000원이다. 금액 렌더와 재배정 후 합계는 다시 브라우저에서 확인하기 전까지 `재검증 예정`이며, 이 요약은 자동 균등 배정이 아닌 형평성 판단 보조값이다.

전체 여섯 객실 중 401호 한 건만 새로 배정한 상태에서 나머지 402·412호가 미배정이어도 `배정된 객실만 저장·통보`가 활성화되는지 확인했다. 저장 뒤 누적 통보는 4건, 미배정 대기는 2건이었고 저장 버튼은 다시 비활성화되어 기존 통보 3건을 중복 기록하지 않았다. 김민지1의 `내 업무`에는 새로 통보된 401호가 보이지만 미배정 402·412호는 보이지 않았다.

예약 예정 시각을 기준으로 얼리 체크인·레이트 체크아웃을 자동 판정하도록 확장했다. 체크인 15:00은 얼리 1시간, 14:00은 얼리 2시간, 체크아웃 13:00은 레이트 2시간으로 표시됐고 정확히 16:00·11:00에서는 특수 상태가 제거됐다. 예약 저장 결과가 객실 카드·상세·필터와 청소 배정 일정에 동일하게 반영되는지 확인했다.

메이드 203호 청소 중 화면에서 이미지 3장을 한 번에 선택해 미리보기 3개를 확인하고 한 장을 개별 제거한 뒤, 메모와 이미지 2장을 객실 특이사항으로 등록했다. 같은 탭에서 관리자 역할로 전환해 203호 객실 상세의 등록자·시각·유형·메모·이미지 2장과 확대 대화상자를 확인했다. 사진만 등록, 메모만 등록, 개인정보 형식 차단, 타 메이드 302호 직접 URL 진입 차단도 각각 별도 상태에서 확인했다.

폭탄방 신고 선결 결정과 객실 단위 산식 로직은 기존 브라우저 검증 범위다. 정본 단가 기준 203호(프리미어)는 기본 20,000원 + 동일 금액 추가 20,000원 = 40,000원, 302호(파셜 오션뷰) 미인정 승인은 기본 20,000원이어야 한다. 관리자 검수·원장과 메이드 주급·이력의 새 금액 일치는 다시 확인하기 전까지 `재검증 예정`이다.

## 확인된 프로토타입 한계

- 체크아웃·연박 신청 자동 구성, 직접 등록, 가능일 제출·담당·순번·통보·실근무 완료 기록은 현재 탭 메모리와 결정적 fixture다. 실제 예약 서버 영속 저장·동시성·불변 이벤트 원장이 아니다.
- 객실 특이사항 이미지 선택·미리보기·관리자 조회는 현재 탭 메모리의 `blob:` URL 시뮬레이션이다. 실제 이미지 서버 전송·재개·영속 보존·악성 파일 검사는 구현하지 않았고 초기화·시나리오 교체·탭 종료 뒤 복원되지 않는다.
- 폭탄방 신고 이미지·검수 결정·객실별 추가금 원장도 현재 탭 메모리와 데모 fixture다. 실제 파일 선택기는 자동화하지 않고 `데모 이미지 2장`으로 신고 흐름을 확인했으며, 실제 이미지 서버 업로드·장기 보존·검수 동시성·급여 송금은 구현하지 않았다.
- 전체 반려 뒤 최초 수행자에게 자동 귀속되는 무급 재청소와 0원 완료 이력도 탭 메모리 데모다. 실제 근로·급여 시스템에 0원 정산을 전송하거나 다른 외부 서비스에서 재배정을 강제하지 않는다.
- `배정 통보 완료`는 앱 내부 화면 갱신 시뮬레이션이며 실제 푸시·SMS·전화 발송이 아니다.
- 타입별 객실 수와 총 청소비는 현재 탭의 배정 fixture를 실시간 합산한 판단 보조값이며 자동 균등 배정·업무 강도 산정·동선 최적화는 구현하지 않았다.
- 타입별 사진 템플릿은 9객실·123장 참고 표본에서 촬영 구역을 정규화한 데모다. 참고 원본은 반입하지 않았고, 9객실은 사진으로 확인한 침실·욕실·배수구 수만큼 반복 필수 슬롯을 생성한다. 나머지 112실은 확정 프로필 없이 최소 공통 슬롯과 `레이아웃 확인 보류`를 사용한다. 촬영 구역 편집/게시 서버·실제 사진 업로드와 자동분류는 아직 없다.
- 참고 객실 표지 사진 일부에는 운영 연락처 등 개인정보성 정보가 있어 원본 자산 재사용이 금지된다. 관리자 템플릿과 메이드 528호 대표 화면의 반응형·접근성·뒤로가기·콘솔은 위 범위에서 통과했지만 전체 편집·게시·서버 흐름을 검증한 것은 아니다.
- 객실 번호·타입·엘리베이터 구역과 타입별 기본 청소요금 16,000/20,000/20,000/30,000원은 8월 시트 정본이다. 인명·예상시간·특수 시각·과거 운영 기록은 데모 fixture다. 앱 상태 미연결은 `운영 상태 미입력`, 시트 단서가 모호한 객실은 `확인 보류`로 구분한다.
